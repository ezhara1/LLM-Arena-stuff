# Steel Horizon

A browser-playable Three.js armored assault game built for Arena.ai. Drive the reinforced **Ironclad-01** tank through an industrial yard, destroy hostile tanks, jeeps, and artillery, and blast a path through block-by-block destructible cover.

## Run locally

```bash
npm install
npm run dev
```

Open the Vite URL shown in the terminal.

## Controls

- **W / S** — drive forward / reverse
- **A / D** — steer
- **Mouse** — aim the turret
- **Click** or **Space** — fire the main cannon

Every wall, roof, barrier, and crate stack is assembled from individual damageable pieces. Player armor is intentionally reinforced: incoming fire is survivable, hull repairs after a short period without being hit, and the cannon reloads between shots.
